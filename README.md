# Klea Dev Portfolio 🚀

A high-performance, interactive developer portfolio built with Svelte, TypeScript, and Vite.

## Features

- **Interactive Games**: Playable coding challenges (CSS Artist, SQL Injection, etc.).
- **Dynamic Content**: Auto-parsing of project READMEs for detailed project pages.
- **Accessibility**: Full a11y support with high contrast and reduced motion modes.
- **Performance**: Optimized for speed with Vite and Svelte.

## Tech Stack

- **Framework**: Svelte 5 + Vite
- **Language**: TypeScript
- **Styling**: Tailwind CSS + Custom CSS
- **Routing**: svelte-spa-router
- **Icons**: Lucide Svelte

## Getting Started

1. **Install Dependencies**:

    ```bash
    npm install
    ```

2. **Run Development Server**:

    ```bash
    npm run dev
    ```

3. **Build for Production**:

    ```bash
    npm run build
    ```

## Project Structure

- `src/lib/components`: Reusable UI components.
- `src/lib/pages`: Route-specific pages.
- `src/lib/services`: Services for data fetching (e.g., resume parser).
- `src/lib/utils`: Helper functions.
- `src/assets`: Static assets.
